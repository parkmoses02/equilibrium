# Equillibrium / SIOR — Rev.L

2026-10-14. Rev.K 기반, 100 × 80 mm, 2층 PCB. 원본 Rev.K는 보존한다.

아래는 PCB 제작 당시의 설계 기록이다. 현재 이중진자 펌웨어(`double_upright`)는 TMC5160의 내부 SPI 램프(`SD_MODE=0`)를 사용한다. 아래 `SD_MODE=1` 설명은 캐리어의 STEP/DIR 배선 기록이며, 이중진자 펌웨어의 모듈 설정이 아니다. [PCBA 폴더](PCBA/UPLOAD_README.md)의 BOM·CPL은 부품 및 방향 검토용으로, 최종 주문 상태와 동일하다고 가정하지 않는다.

## 열기

`esp32_wroom_tmc5160_bob_revL.kicad_pro`를 KiCad에서 연 뒤 같은 이름의 PCB를 연다.
`RevL_3D_top.png`는 부품 장착 미리보기다. ESP32와 BOB 모듈 자체는 모델이 없고 **소켓만 표시**된다.
`RevL_pad_manifest.json`은 실제 저장된 패드 좌표와 네트, `RevL_verification.json`은 독립 검사 결과다.

## 변경 사항

- HEDS-9100 두 개를 하나의 J5 6핀 **2.54 mm 수헤더**에 연결: 전원 두 가닥만 공유, A/B는 각각 독립.
- U3/U4 = **SN74LVC14AD, SOIC-14, 3.3V 전원**. 각 채널마다 인버터 두 단을 통과하므로 원래 A/B 극성 유지. HC14, HCT14, HC574로 대체 금지.
- J3 기존 엔코더의 A/B와 GPIO34/35, R1~R4 회로는 유지. **주의: Rev.K의 J3.4는 5V였지만 Rev.L은 사용자 요청의 3.3V 엔코더 기준으로 3.3V로 변경했다.** 기존 하네스 순서는 같고 전압은 다르다. 기존 센서가 실제로 5V 전원을 요구하면 이 설계 그대로 발주하지 말고 전원 선택을 재검토한다.
- J4 모터는 아래쪽 오른편, J5 새 엔코더는 아래쪽 왼편. J3는 왼쪽 아래, J6 모터 피드백과 J7 DIAG는 따로 인출.
- SD_MODE=1용 STEP/DIR를 연결. CLK16-GND는 실제 동박으로 직접 연결.
- 전원단자 각 패드 아래 `- GND` / `+24V` 표시를 개별 정렬. `Equillibrium`(요청한 철자), `SIOR`, `Rev.L` 추가.
- 소켓 피치 2.54mm 유지. ESP32 두 줄 중심 25.40mm, BOB 두 줄 중심 35.56mm. BOB 각 줄 11핀 = 첫–끝 중심 25.40mm.
- ESP 안테나 예상 영역 아래 양면 동박/배선 금지 영역. RF 성능 및 실제 안테나 외형은 실물 확인 대상.

## J5 — 두 진자 엔코더 공용 커넥터

**기판 글씨가 정방향인 윗면에서 왼쪽 → 오른쪽.** 사각 패드/실크 `1`이 첫 핀이다.

| J5 핀 | 실크 | 연결할 선 | 변환 후 MCU |
|---|---|---|---|
| 1 | 5V | HEDS 1, 2의 VCC를 함께 | 전원, GPIO 아님 |
| 2 | G | HEDS 1, 2의 GND를 함께 | 공통 GND |
| 3 | A1 | HEDS 1 A | GPIO36 |
| 4 | B1 | HEDS 1 B | GPIO39 |
| 5 | A2 | HEDS 2 A | GPIO32 |
| 6 | B2 | HEDS 2 B | GPIO33 |

Broadcom HEDS-9100 모듈 공식 핀 번호는 **1=GND, 2=NC, 3=A, 4=VCC, 5=B**다.
모듈 번호는 J5 번호와 다르다. 구매 모듈/추가 어댑터의 실제 핀 번호와 방향을 대조한다.
HEDS-9100은 A/B 2채널이고 인덱스 N/Z 출력이 없다. 정확한 CPR은 옵션 코드와 코드휠에 달려 있다.

분기 예: J5.1 → 두 엔코더의 4번; J5.2 → 두 엔코더의 1번.
**A1과 A2, B1과 B2를 서로 묶지 않는다.** J5의 A/B는 5V 측이므로 다른 ESP 핀이나 J6에 직접 점퍼하지 않는다.
센서 바로 옆에도 각 100nF 바이패스 콘덴서를 두는 것을 권장한다. 보드 C3만으로 긴 케이블 끝의 디커플링을 대체하지 않는다.

## 나머지 커넥터

| 커넥터 | 윗면 기준 핀 순서 | 설명 |
|---|---|---|
| J1 | 왼쪽 1=GND, 오른쪽 2=+24V | 5.08mm 2핀 단자대. USB 전원과 혼동 금지 |
| J3 | 위→아래: A, B, GND, **3.3V**, GND | 기존 5핀 암소켓, GPIO34/35 |
| J4 | 왼→오: A2, A1, B2, B1 | JST-PH 2.0mm 4핀 수헤더; 기존 전기적 핀 번호 유지 |
| J6 | 왼→오: 3.3V, GND, ENCA, ENCB, ENCN | TMC 모터 피드백용. **3.3V 논리 전용**, HEDS raw 5V 연결 금지 |
| J7 | 위→아래: DIAG0, GND | MCU에 자동 연결되지 않은 출력. 오픈드레인 설정 시 3.3V 풀업 필요 |
| J2 | 위→아래: IO32, IO33, IO25, IO26, GND, IO21, IO22, 3.3V | IO32/33은 HEDS2와 공유. 두 핀에 외부 출력을 또 연결하지 말 것 |

J6는 모터 엔코더용으로 추가한 별도 슬롯이며 J3와 자동 연결되지 않는다. 기존 엔코더를 TMC에 연결하려면 J6에 맞춰 하네스를 구성해야 한다.
모터의 두 코일을 서로 다른 상으로 연결하며, **전원을 켠 상태에서 모터 커넥터를 빼거나 꽂지 않는다.**

## TMC와 펌웨어

- SD_MODE=1: REFL/STEP=GPIO14, REFR/DIR=GPIO27, DRV_ENN=GPIO13(active-low).
- MOSI=23, MISO=19, SCK=18, CS=5. CLK16=GND, 내부 클록 사용.
- R5=10k EN 풀업으로 MCU가 초기화되지 않았을 때 드라이버 비활성. R6/R7=100k STEP/DIR 풀다운.
- BOB 모듈의 SD_MODE 스트랩은 실물에서 설정해야 한다. 캐리어 배선만으로 모듈 모드가 바뀌지 않는다.
- **펌웨어는 이번 작업에서 수정하지 않았다.** 새 HEDS 입력 GPIO36/39/32/33, 해당 코드휠의 4체배 카운트 수 및 두 진자 상태 처리는 별도 반영해야 한다.
- J6 모터 피드백도 배선만으로 탈조 자동 보정이 되지는 않는다. 관련 TMC 설정/카운트 비교가 필요하다.

## 전원/케이블

5V는 ESP 보드의 USB 5V 경로에서 공급한다. 추가 HEDS 두 개는 공식 데이터시트 최대값 기준 합계 80mA이며 ESP와 다른 센서 소비량도 포함해 USB 전원 여유를 확인한다. 엔코더 단에서 5V 공급 범위를 확인한다.
USB를 끈 상태에서 외부 5V를 J5에 역주입하지 않는다. 24V와 5V, 3.3V는 서로 연결하지 않는다.
AWG24는 이번 엔코더 하네스의 전원/신호에 사용할 수 있으나 길이·접촉 상태·사용 접점의 AWG 범위를 확인해야 한다. 모터 전류 배선 규격을 의미하지 않는다.
신호는 GND와 가까이 배치하고 모터 배선과 분리한다. 공유 GND 1가닥의 6핀 단일종단 하네스는 차동 전송이 아니므로 긴 케이블에서 노이즈 면역을 보장하지 않는다. 최대 속도에서 오실로스코프로 파형/누락을 확인한다.

## 제조/검증 범위

- SIOR 로고: 제공 이미지의 파란 글자 윤곽을 16.5 × 4.02mm 흰색 앞면 실크 도형으로 반영. 번개는 인쇄하지 않는 공간이다. 전기적 연결/배선은 변경하지 않았다. 변경 전 보드는 `build_record/before_SIOR_logo.kicad_pcb`에 보존.

- 최종 KiCad DRC: 오류 0, 경고 0, 미연결 0. 독립 자동 검사 288개 통과. 회로도 일치 검사는 제외.
- 모든 모터 상전류 경로는 1.5mm 트랙으로 같은 레이어에서 연결하며 작은 신호용 비아를 경유하지 않는다. 동박/도금/주변온도에 따른 전류 허용량 실물 검증은 별도다.
- J5를 빼면 사용 중인 버퍼 입력이 떠서 허위 카운트가 발생할 수 있다. 엔코더 연결 확인 후 제어를 활성화하고 전원이 켜진 상태에서 탈착하지 않는다.
- 부품표는 위 표를 사용한다. 제공 위치 파일은 KiCad 원본 `.pos`이며 JLCPCB용 부품 선택/회전 보정 BOM·CPL은 아직 확정하지 않았다.

- Gerber는 Rev.L 보드와 같은 버전만 사용. 양면 동박, 양면 마스크, 실크, 외곽, 드릴을 함께 확인.
- 위치 원본 파일은 KiCad 좌표/회전이다. **JLCPCB 부품 모델별 회전 보정은 검증되지 않았으므로 PCBA 최종 업로드 파일로 간주하지 않는다.** Rev.J/K의 BOM/CPL은 재사용 금지.
- Rev.K와 마찬가지로 원본에 회로도가 없어 ERC 및 회로도-보드 일치 검사는 수행할 수 없다. 독립 패드/연결 검사가 이를 전부 대체하지 않는다.
- DRC 결과는 동박/실크 설계 규칙 검사이며 물리적 맞춤·온도상승·케이블 노이즈·24V 과도응답의 실물 인증이 아니다.
- 발주 전 1:1 도면에 ESP/BOB 실물을 대조하고, 소켓 높이/방열판/USB 및 하네스 접근공간을 확인한다.
- 첫 전원 투입 전 저항·극성·단락 검사 후 전류 제한을 사용한다. 모듈 전원 커패시터 및 역극성 보호 유무는 모듈 자체 사양을 확인한다.
